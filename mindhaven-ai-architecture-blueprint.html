🤖 AI Agent Layer

Agent 1 – Empathetic Listener Listener

  • System prompt: warm, non-judgmental, active-listening persona
  • Context-aware: uses last 10 turns of session history
  • Temperature: 0.75 (expressive)
  • Appends mandatory professional-care disclaimer to every reply
  • Never diagnoses or prescribes

Agent 2 – Proactive Care Coach Coach

  • System prompt: evidence-based wellness coach persona
  • Receives risk_level context (low / moderate / high)
  • Temperature: 0.65 (focused, actionable)
  • Outputs 2–4 bullet-point coping suggestions
  • Tone adapts to severity: grounding → calming → preventive

🛡 Safety Filter Layer

assess_risk_level(text) — runs synchronously before any LLM call

High-risk keywords (16):

suicide kill myself self-harm want to die overdose end my life better off dead + 9 more

Moderate-risk keywords (14):

hopeless depressed panic attack overwhelmed burnout lonely + 8 more

HIGH → immediately triggers emergency referral + 8 helplines

💾 State Management

No database. Flask server-side session only.

session["chat_history"] — list of dicts
{"role": "user"|"assistant", "content": "…"}

Bounded to last 20 messages to avoid token overflow.
Cleared on POST /api/clear_chat or session expiry.

Privacy guarantee: nothing written to disk.

📦 Static Data Stores

In-memory Python constants — no DB required.

  • HELPLINES — 8 verified crisis contacts (India, US, UK, AU, Global)
  • COPING_RESOURCES — 6 evidence-based exercises (Breathing, Grounding, Journaling, Mindfulness, Movement, Self-Compassion)
  • HIGH_RISK_KEYWORDS — 16 crisis-level terms
  • MODERATE_RISK_KEYWORDS — 14 distress-level terms
